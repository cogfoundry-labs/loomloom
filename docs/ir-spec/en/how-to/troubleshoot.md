# Troubleshoot TemplateSpec v2

1. Parse failure: check lowerCamel fields and unknown properties.
2. Local check failure: follow the rule ID and invalid example.
3. Version creation failure: check authority revisions, target ports, DAG, and safe domains.
4. Workbook failure: check input keys, blank policy, MIME, and cardinality.
5. Run failure: inspect the Step's actual model, contract, Gateway request ID, Provider error, and Artifacts.
