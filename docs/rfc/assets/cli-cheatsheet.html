loomloom / CLI cheat sheet

The whole intent-first CLI on one page — every common task, one command.

Proposed surface from RFC-0002. Names provisional. Binary shown as loom; loomloom stays a permanent alias.

The core loop — run any AI work

run download → run check free → run quote free → run start --yes paid · wallet gate → run watch → run results

Or the whole safe loop in one line: loom run <work> --input input.xlsx. The same command runs an official template, a private one, or a Market SkillBot — the CLI resolves which.

Set up & check

Get connected and confirm your setup.

Log in
loom login
Who am I / which server / token source
loom whoami
Check my setup is healthy
loom doctor
Switch server profile
loom use <server>

Find & inspect

Two readers cover everything you own or can run.

Find AI work to run (official + Market)
loom search "<query>"
The list of my own work / runs / SkillBots / usage (“list” only enumerates — publishing is publish)
loom list work runs skillbots usage
Inspect anything by id
loom get <id>

Run AI work

One verb set — official template, private template, or Market SkillBot.

Get a blank input template
loom run download <work> -o input.xlsx
Validate my input (free)
loom run check <work> --input input.xlsx
Estimate the cost (free)
loom run quote <work> --input input.xlsx
Run it (paid — needs --yes)
loom run start <work> --input input.xlsx --yes
…or do the whole safe loop in one line
loom run <work> --input input.xlsx
Watch a run to completion
loom run watch <run-id>
Get the results
loom run results <run-id> -o results.xlsx
Cancel a run
loom run cancel <run-id> --yes

Build & publish

Turn your method into a sellable SkillBot.

Compile my TemplateSpec (the .json that defines my AI work) into a SkillBot
loom build spec.json
Add a new version
loom build spec.json --as-version <id>
Publish it on the Market
loom publish <work> --fee 0.5
Change price / profile
loom publish update <id>
Take off Market / put back
loom publish pause <id> · loom publish resume <id>
See my earnings
loom list earnings

Use in your agent

Install a SkillBot as a local agent skill.

Install as a local agent skill
loom install <ref> -o <dir>
Remove it
loom uninstall <dir>

For agents & scripts — machine mode

Stable, parseable, non-interactive by default.

Get JSON on any command (data at .data, cursor at .meta.nextCursor)
loom <cmd> --json
Pick exact fields
loom get <id> --json --fields id,status,url
Confirm without a prompt · plan without doing it
... --yes ... --dry-run
Pass a large input from a file
loom run start <work> --input @rows.jsonl --yes

Every command is loom <verb> …. There are no template / template-spec / market / listing / creator groups to learn, no client-request-id to mint, and no *T units to convert — the same knowledge runs an official template, a private one, or a Market SkillBot.
